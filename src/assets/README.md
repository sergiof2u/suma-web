Las imágenes del sitio van acá, no en `public/`.

Puestas en esta carpeta, Astro las comprime y genera los tamaños que hagan
falta. En `public/` se sirven crudas, y una foto de 4 MB sin optimizar es un
problema real: mucha gente abre este sitio desde el celular para decidir si
sube a Subachoque.

Carpetas sugeridas: `talleres/`, `talleristas/`, `tienda/`, `joyeria/`,
`yoga/`, `espacio/`.
